ယခုဖိုင်များသည် လက်ရှိ CLI website ကို အခြေခံထားသော တည်းဖြတ်နိုင်သည့်
website source code အပြည့်အစုံ ဖြစ်ပါတယ်။ HTML နှင့် CSS ကို သီးခြားထားပြီး
ဖတ်ရလွယ်အောင် စာကြောင်းခွဲထားပါတယ်။ Mobile menu အတွက် JavaScript ပါဝင်ပါတယ်။

၁။ စတင်အသုံးပြုနည်း

  1) CLI_Website_Source.zip ကို Download လုပ်ပါ။
  2) Windows တွင် right-click > Extract All ကိုနှိပ်ပြီး ZIP ကိုဖြည်ပါ။
  3) CLI_Website_Source folder ထဲက index.html ကို double-click နှိပ်ပါ။
  4) Chrome, Edge သို့မဟုတ် Firefox တွင် website ကို ကြည့်ရှုနိုင်ပါတယ်။

  XAMPP၊ PHP၊ Node.js၊ database သို့မဟုတ် build command မလိုအပ်ပါ။
  Google Fonts အတွက် အင်တာနက်လိုအပ်ပြီး offline ဖြစ်နေပါက စက်ထဲရှိ
  အစားထိုး font ကို အသုံးပြုပါမယ်။ Social links တွေအတွက်လည်း အင်တာနက်လိုပါတယ်။

၂။ ပါဝင်သောဖိုင်များ

  index.html          Website စာသား၊ section များနှင့် contact links
  styles.css          အရောင်၊ font၊ layout၊ animation နှင့် responsive styles
  script.js           Mobile menu၊ scroll effects နှင့် copyright year
  assets/cli-logo.png  သင်ပေးထားသော မူရင်း CLI logo
  README_MM.txt       ဤအသုံးပြုနည်း

  ဖိုင်နာမည်နှင့် assets folder ကို မပြောင်းဘဲ folder structure အတိုင်း ထားပါ။
  HTML တစ်ဖိုင်တည်းကို အခြားနေရာသို့ ရွှေ့ပါက CSS၊ JavaScript၊ logo
  တို့နှင့် ချိတ်ဆက်မှု မမှန်တော့နိုင်သောကြောင့် folder တစ်ခုလုံးကို ရွှေ့ပါ။

၄။ Code ကို တည်းဖြတ်နည်း

  VS Code သို့မဟုတ် အခြား text editor တစ်ခုတွင် folder ကိုဖွင့်ပါ။
  ဖိုင်များကို UTF-8 encoding ဖြင့် သိမ်းပါ။ မြန်မာစာသည် Unicode ဖြစ်ပါတယ်။

  စာသားပြင်ရန် — index.html ထဲက သက်ဆိုင်ရာ section ကိုပြင်ပါ။
  HTML comments တွင် WHO WE ARE, OUR SERVICES, 5D, 6C, CONTACT စသည်ဖြင့်
  ခေါင်းစဉ်များ ရေးပေးထားပါတယ်။

  အရောင်ပြင်ရန် — styles.css အစရှိ :root ထဲက variable များကိုပြင်ပါ။
    --forest: #0b2d25   အစိမ်းရင့်
    --green:  #17624e   အဓိကအစိမ်း
    --gold:   #f2b84b   ရွှေရောင်
    --cream:  #f7f5ef   နောက်ခံအရောင်

  Logo ပြင်ရန် — assets/cli-logo.png ကို နာမည်တူပုံအသစ်ဖြင့် အစားထိုးပါ။

  Email ပြင်ရန် — မြင်ရသော email စာသားနှင့် href="mailto:..." နှစ်ခုလုံးပြင်ပါ။
  Phone ပြင်ရန် — မြင်ရသောဖုန်းနံပါတ်နှင့် href="tel:..." နှစ်ခုလုံးပြင်ပါ။
  Social link ပြင်ရန် — သက်ဆိုင်ရာ <a> tag ၏ href ကိုပြင်ပါ။

  Browser ကို refresh လုပ်ပြီး ပြင်ထားသည်များကို ကြည့်ပါ။

  Phone link သည် ဖုန်းခေါ်နိုင်သော device တွင် dialer ကိုဖွင့်ပါတယ်။
  Free Consultation button သည် contact section သို့ သွားပါတယ်။
  ဤ code တွင် booking database သို့မဟုတ် message submission backend မပါဝင်ပါ။

၆။ Hosting ပေါ်သို့ တင်လိုပါက

  index.html၊ styles.css၊ script.js နှင့် assets folder ကို hosting ၏
  public folder ထဲသို့ တစ်စုတည်း upload လုပ်ပါ။ Server-side code မလိုအပ်ပါ။
  Domain name သည် hosting/DNS ဘက်တွင် ချိတ်ဆက်ရသောအရာဖြစ်ပြီး
  HTML ထဲရှိ <title> စာသားပြောင်းရုံဖြင့် website address မပြောင်းပါ။

  Code copy ပြင်ခြင်းသည် လက်ရှိ online website ကို အလိုအလျောက် မပြောင်းပါ။
